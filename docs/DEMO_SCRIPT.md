# 90-second WebMCP demo script

Use the public Vercel alias, then keep Chrome DevTools open at **Application → WebMCP** throughout the first half of the recording.

1. **0:00–0:12 — prove the contract.** Show the eight registered tools. Say: “This portfolio exposes a stable WebMCP contract, not scraped résumé text.”
2. **0:12–0:30 — show evidence retrieval.** Invoke `search_expertise` for a named skill, then `find_relevant_work` for a concrete requirement. Open the resulting human-view route.
3. **0:30–0:48 — show judgement, not keyword search.** Call `map_requirements_to_evidence` with two matching requirements and one intentionally unsupported one. Point out the evidence source and the no-guarantees disclaimer.
4. **0:48–1:04 — show a safe action.** Compare engagement options, then create a discovery brief. Emphasise that the brief is reviewable and browser-session-only.
5. **1:04–1:18 — show human control.** Call `prepare_contact_request` with demo data. Open `/contact` and show the populated fields plus the absence of any submit transport.
6. **1:18–1:30 — show impact.** Open the repository README. Point to the five-minute fork flow, the two JSON files, `npm run validate-content`, and the Vercel deploy button.

## Recording checklist

- Use the canonical public alias rather than a generated Vercel deployment URL.
- Keep the WebMCP panel visible for at least one real invocation.
- Use only synthetic contact data in the demo.
- Record the `webmcp-evals` terminal summary showing `Passed steps: 8/8` as a closing proof shot.
